# Seller and Inventory Management System
Introduction

The Seller and Inventory Management System is a MySQL-based database project designed to manage seller details, maintain product and stock information, track product availability, and generate inventory status reports.

Objectives

Create Seller and Inventory tables.
Establish relationships between sellers, products, and stock.
Maintain seller product information.
Track available and unavailable products.
Generate inventory status reports.

Technologies Used

MySQL
SQL
GitHub

Database Tables

Seller: Stores seller names, email addresses, phone numbers, and addresses.
Inventory: Stores product details, prices, stock quantities, and seller references.

Features

Seller information management.
Product and stock maintenance.
Available and unavailable product tracking.
Low-stock identification.
Inventory status reports.

Conclusion

This project demonstrates how MySQL can be used to manage seller information, maintain inventory records, monitor product availability, and generate inventory reports.
